About the Project

Chrome Domain Requester is a configurable automation project designed to send HTTP requests to a specified domain at varying time intervals, simulating ordinary browser visits where technically appropriate.

Configuration

Set the "DOMAIN_NAME" variable to the target domain before running the project.

DOMAIN_NAME="https://example.com"

Replace "https://example.com" with the domain you own or are authorized to test.

Key Features

- Configurable target: Change the destination using "DOMAIN_NAME".
- Automatic requests: Send requests automatically after startup.
- Variable intervals: Schedule requests at different time intervals instead of using a fixed delay.
- Browser-like behavior: Where appropriate, use legitimate browser navigation and standard HTTP headers.
- Configurable operation: Keep the target domain and scheduling settings easy to modify.
- Responsible usage: Respect website terms, rate limits, and server resources. Do not use the project to generate deceptive traffic, bypass security controls, or overload websites.

درباره پروژه

پروژه Chrome Domain Requester یک ابزار خودکار و قابل تنظیم است که درخواست‌هایی را در بازه‌های زمانی متفاوت به یک دامنه مشخص ارسال می‌کند. هدف آن شبیه‌سازی بازدیدهای معمول مرورگر، در مواردی است که این کار از نظر فنی مناسب و مجاز باشد.

تنظیمات

برای مشخص‌کردن دامنه مقصد، متغیر "DOMAIN_NAME" را پیش از اجرای پروژه تنظیم کنید.

DOMAIN_NAME="https://example.com"

به‌جای "https://example.com" دامنه‌ای را قرار دهید که مالک آن هستید یا اجازه آزمایش آن را دارید.

ویژگی‌های اصلی

- تعیین دامنه مقصد: تغییر آدرس مقصد با استفاده از متغیر "DOMAIN_NAME".
- ارسال خودکار درخواست: شروع ارسال درخواست‌ها پس از اجرای برنامه.
- بازه‌های زمانی متغیر: ارسال درخواست‌ها در زمان‌های متفاوت به‌جای استفاده از یک فاصله ثابت.
- رفتار مشابه مرورگر: استفاده از پیمایش واقعی مرورگر و سرآیندهای استاندارد HTTP در صورت نیاز.
- تنظیمات ساده: امکان تغییر آسان دامنه و زمان‌بندی درخواست‌ها.
- استفاده مسئولانه: رعایت قوانین وب‌سایت، محدودیت نرخ درخواست و منابع سرور. استفاده برای ایجاد ترافیک جعلی، دورزدن کنترل‌های امنیتی یا ایجاد بار مخرب روی وب‌سایت‌ها مجاز نیست.
